# 🎓 LearnPath AI

Pick a topic you want to learn and get:

1. **The best courses** for your level (free-only filter, learning-style filter)
2. **Notes and practice labs** for that topic
3. **A simple AI roadmap** (modules, goals, practice tasks) with progress tracking
4. **AI study notes** for every module (downloadable)
5. **A quiz** made from your roadmap (pass mark 70%)
6. **A badge (PNG)** when you finish all modules and pass the quiz
7. **An AI study assistant** to ask questions

Built with Streamlit. Works with **Claude (Anthropic)** or **Groq**. You choose in the sidebar.

---

## How it works (and what it does NOT do)

| Feature | How it really works |
|---|---|
| "Best course from all platforms" | Ranked from a **curated list** in `data/courses.json` using clear rules in `courses.py` (level, learning style, has practice). Coursera/Udemy/edX have no open API and scraping breaks their rules, so the app never guesses courses with AI. |
| Handwritten / self-made notes | **Not possible to find automatically.** No platform labels notes as "handwritten". The app lists good free written notes and the AI writes module notes for you. |
| Practice labs | Curated list per topic (TryHackMe, PortSwigger, Kaggle, LeetCode, ...). |
| Roadmap, notes, quiz, assistant | Generated by the AI you choose. The AI can make mistakes: check important facts. |
| Badge | Self-awarded by this app. It is **not** an official certificate. |
| Saving progress | Progress lives in the browser session. **Refreshing the page clears it.** (Streamlit Cloud has no database.) |

## Files

```
app.py                  the Streamlit app (UI)
llm.py                  Claude + Groq wrapper and all AI prompts/validators
courses.py              loads the catalog and ranks courses
badge.py                draws the badge PNG
data/courses.json       the curated courses, notes and labs  <- edit this to add topics
check_links.py          checks that every link in courses.json still works
test_app.py             automated tests (optional)
requirements.txt        Python packages
.gitignore              keeps secrets out of GitHub
.streamlit/secrets.toml.example   how to store API keys
```

## Run on your computer

1. Install Python 3.10 or newer.
2. Open a terminal in the project folder.
3. Create a virtual environment and install packages.

   Windows:
   ```
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
   Mac / Linux:
   ```
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
4. Add your key (choose one way):
   - Easiest: run the app and paste the key in the sidebar.
   - Or copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and put your key inside.
5. Start the app:
   ```
   streamlit run app.py
   ```

Get keys: Anthropic Console (console.anthropic.com) for Claude, console.groq.com for Groq.

## Check the links

```
python check_links.py
```
`BROKEN` = fix that link in `data/courses.json`. `BLOCKED` = the site refuses scripts; open it in your browser to check.

## Push to GitHub using the website (no Git needed)

1. Go to **github.com** and log in.
2. Click the **+** (top right) → **New repository**.
3. Repository name: `learnpath-ai`. Choose **Public** (Streamlit free hosting needs a public repo). Do **not** tick "Add a README" (you already have one). Click **Create repository**.
4. On the empty repo page click **uploading an existing file**.
5. Open your project folder on your computer. Select **everything inside it** and drag it into the GitHub page. Make sure these are included: `app.py`, `llm.py`, `courses.py`, `badge.py`, `check_links.py`, `test_app.py`, `requirements.txt`, `README.md`, `.gitignore`, the `data` folder, and `.streamlit/secrets.toml.example`.
   - **Do NOT upload** `venv`, `__pycache__`, or a real `secrets.toml`.
   - If the `data` folder does not upload by drag-and-drop, click **Add file → Create new file**, type `data/courses.json` as the name, and paste the file content.
6. Scroll down, write a message like `first version`, and click **Commit changes**.
7. Refresh the page and check that all files and the `data` folder are there.

## Deploy on Streamlit Community Cloud

1. Go to **share.streamlit.io** and sign in with GitHub.
2. Click **Create app** → **Deploy a public app from GitHub**.
3. Choose your repository `learnpath-ai`, branch `main`, main file path `app.py`.
4. (Optional) Click **Advanced settings → Secrets** and paste:
   ```
   GROQ_API_KEY = "gsk_your-key-here"
   ```
5. Click **Deploy**. The first build takes a few minutes. You get a link like `https://your-app-name.streamlit.app`.

**Important about keys on a public app:** if you put your key in Secrets, *anyone with the link spends your API credit.* Safer options:
- Leave Secrets empty and let each visitor paste their own key in the sidebar (they can use Groq's free tier), or
- Put only a **Groq** key (free tier, limited) and never a paid Claude key, or
- Set the app to private in its settings.

Menus on these websites change sometimes. If a button has a different name, look for the closest one.

## Change the AI models

Models are listed at the top of `llm.py` in `PROVIDERS`. If a provider retires a model, replace the model ID there.

## Add a new topic

Open `data/courses.json`, copy one topic block, and edit it. Each course needs: `title, platform, url, level (Beginner/Intermediate/Advanced), price (Free / Free to audit / Freemium / Paid), format (Video/Text/Interactive/Mixed), hours, has_labs, why`. Hours are rough estimates, so adjust them. Make sure every level has at least one course (the tests check this). Then run `python check_links.py`.

## Troubleshooting

- **"API key was rejected"**: wrong key, or a key for the other provider.
- **"Model name was not accepted"**: update the model ID in `llm.py`.
- **"Rate limit"**: wait a minute or switch to the other provider.
- **Quiz or roadmap fails**: click the button again; the app already retries once.
- **Progress disappeared**: the page was refreshed. Progress is not saved between sessions.
